# MyPick KBO Fantasy Analytics Platform

MyPick is a KBO sports analytics platform that transforms complex baseball records into intuitive fantasy scores, dynamic player valuations, user rankings, and point-based prediction experiences.

## Project Purpose

MyPick was built to make complex KBO baseball data easier to understand and more engaging for fans. Traditional baseball records contain many detailed statistics, but casual fans often struggle to compare players across positions, roles, and recent performance trends.

MyPick transforms raw KBO game records into fantasy scores, dynamic player prices, team rankings, and point-based prediction features, giving users a simpler and more interactive way to evaluate players and follow games.

## Key Features

- KBO game data collection and daily update pipeline
- Fantasy scoring system for batters and pitchers
- Dynamic player pricing model
- 15-player fantasy team construction
- Captain-based team scoring
- User asset and ranking system
- Point-based game prediction system
- Player search and player detail pages
- Automated production deployment pipeline

## Tech Stack

- Backend: Flask, Python
- Database: SQLite
- Frontend: Jinja2, HTML, CSS, JavaScript
- Deployment: AWS Lightsail, Ubuntu, Nginx, Gunicorn, systemd
- Automation: systemd timers, scheduled data pipelines

## Data Privacy Notice

This repository is a portfolio-safe version of MyPick. Production secrets, private user data, the production database, logs, backups, and server keys are excluded.
