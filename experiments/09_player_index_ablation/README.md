# Player-Index Ablation

**Question:** Do batter and starting-pitcher indices add information beyond conventional pregame variables?

**Result:** The combined model reduced Log loss from 0.683942 to 0.666135, reduced Brier score from 0.245313 to 0.236498, increased AUC from 0.575781 to 0.635275, and increased accuracy from 54.33% to 59.62%.

**Decision:** The research hypothesis is supported retrospectively. Final confirmation requires a frozen future ledger.
