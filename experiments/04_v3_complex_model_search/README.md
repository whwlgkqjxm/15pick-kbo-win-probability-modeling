# V3 — Broad complex-model negative result

## Hypothesis

Can 763 candidate columns and nine model families beat V2?

## Data and protocol

37 configurations, five rolling folds, roughly 610 temporal fits.

The experiment follows the date-level strict-prior contract applicable at that stage. Protocol differences are not hidden; absolute metrics from different protocols are not ranked as if they were one common leaderboard.

## Result

V3 ensemble Log loss 0.677185, worse than V2 0.670610.

## Decision

Reject complexity without improved temporal probability quality.

## What changed next

Feature proliferation and nonlinear capacity did not create independent information.
