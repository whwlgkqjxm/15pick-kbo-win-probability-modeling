# 선수 평균수입 지표는 KBO 승리확률 예측을 개선하는가?

이 저장소는 판타지 스포츠·포인트 기반 예측 플랫폼 **MyPick**에서 시작된 데이터 사이언스 연구다.

MyPick에서는 복잡한 타격·투구 기록을 하나의 직관적인 **선수 수입** 점수로 변환해 팬들이 선수 활약도를 쉽게 비교하도록 했다. 여기서 다음 질문이 생겼다.

> 이 단순화된 선수 수입 지표는 사용자에게 보기 편한 점수일 뿐인가, 아니면 실제 미래 경기 결과에 관한 정보도 보존하는가?

## 연구 질문

> **공식 KBO 경기 기록으로 구축한 역할별 strict-prior 복합 선수 활약도 지표는 기존 팀 전력과 일반적인 경기 전 기록만 사용하는 모델보다 KBO 경기의 승리확률 예측을 개선하는가?**

## 핵심 결과

같은 모델, 같은 학습 구간, 같은 팀 전력 변수를 유지하고 선수 평균수입 변수만 추가·제거했다.

| 모델 | Log loss ↓ | Brier ↓ | AUC ↑ | 정확도 ↑ |
|---|---:|---:|---:|---:|
| 선수 평균수입 없음 | 0.683942 | 0.245313 | 0.575781 | 54.33% |
| 타자+선발 평균수입 포함 | **0.666135** | **0.236498** | **0.635275** | **59.62%** |

- Log loss 개선: **−0.017807**
- Brier 개선: **−0.008815**
- AUC 상승: **+0.059494**
- 정확도 상승: **+5.29%p**
- 날짜 단위 bootstrap 개선 확률: **98.69%**
- 95% 구간: **[−0.033154, −0.002114]**

역할별로는 선발투수 평균수입이 가장 큰 단독 개선을 보였고, 타자 평균수입을 함께 사용했을 때 성능이 추가로 개선됐다.

## 학문적 상태

최근 720경기 학습법은 현재 가장 좋은 개발 결과지만 2026 결과가 연구 과정에서 이미 관측되었다. 따라서 최종 독립 테스트라고 표현하지 않는다. 시간순 CV로 선택된 모델에서도 선수 평균수입 추가 시 Log loss가 `0.683516 → 0.667390`으로 개선됐으며, 최종 일반화 주장은 동결된 미래 경기 prospective 검증 이후에 한다.
