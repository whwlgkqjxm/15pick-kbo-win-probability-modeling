# Derived modeling data

`V12_MODELING_DATASET.csv` is the frozen 1,824-row decision-game table used to reproduce the core V12 logistic models. It contains official-derived game identifiers, outcomes, pregame team features, clean starter features, starter names and IDs, and the selected batter-lineup block.

This file is a restricted artifact in the private review build. It is not the full raw KBO archive, and its inclusion does not establish clearance for unrestricted redistribution. Before any public release, complete the applicable path in [`docs/data_release_policy.md`](../../docs/data_release_policy.md).
