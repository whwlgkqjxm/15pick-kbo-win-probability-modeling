# Derived modeling data

`V12_MODELING_DATASET.csv` is the frozen 1,824-row decision-game table used to reproduce the core V12 logistic models. It contains official-derived game identifiers, outcomes, pregame team features, clean starter features, and the selected new batter-lineup block.

It is not the full raw KBO archive. Before public release, review `docs/data_release_policy.md` and confirm that this derived table matches the intended distribution policy.
